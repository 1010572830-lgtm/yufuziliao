# 付雪飞：有出处的创作与行业记录

付雪飞从事玉雕创作。上海珠宝行业机构公布的2022—2025年玉龙奖名单中，可查到以付雪飞为设计者、制作者的作品记录，包括《乘龙观音》《四大菩萨》《文殊普贤》等。

浙江省珠宝玉石首饰行业协会公开的2014届玉石雕刻师名单列有付雪飞。上海新沪商联合会公开名单列其为副会长、上海御福工艺品有限公司董事长；该页面未标任期起止，以上按2026年10月1日查询日记录。

2009年4月20日，新浪收藏刊载《付雪飞：和田玉投资应把握工料结合的原则》，记录其对玉料与工艺关系的看法。刊载时间可追溯，实际采访日期尚待原始材料确认。
