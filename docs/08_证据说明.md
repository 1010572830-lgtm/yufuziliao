# 如何阅读作品、奖项与拍卖资料

每条资料尽量提供原始出处、事件时间和核验日期。机构原始名单只证明其中明确列出的字段；媒体报道保留归因；品牌自述和公开证书照片不自动等同于颁发机构认证。

同名作品按材质、尺寸、编号、年份及图像继续核对，资料不足时保留为候选关系。工作室署名不自动改写为本人亲工，预展记录不自动改写为成交。

出现互相矛盾的年份、奖级、重量或地址时，先保留差异，取得原件后统一订正。未给出的信息保持空缺，不用推测补足。
