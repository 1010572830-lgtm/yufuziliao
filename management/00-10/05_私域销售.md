# 05｜御府成交中心·私域销售

## 职责

管理微信私域、老客户、新咨询、复购、转介绍、预约鉴赏、销售跟进与高客单成交。

## 客户流程

内容/来源 → 客户ID → 需求与用途 → 预算范围 → 候选货号 → 看货/补资料 → 报价 → 交易确认 → 成交/暂缓 → 售后 → 复购/转介绍。

## 销售原则

- 客户未说的信息留空，不推断财富、身份或偏好。
- 不一次堆几十件商品，先明确需求再少量匹配。
- 每次沟通必须有“下一动作”和下次跟进时间。
- 客户联系许可、来源内容ID与销售负责人分开记录。
- 不把活动方案写好当成客户已被邀约。

CRM结构、客户分层、首次回复模板、16环节预约鉴赏/咨询接待执行卡，以及发布/接客/保管/财务/现场五岗交接框架。
