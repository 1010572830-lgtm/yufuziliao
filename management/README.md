## 当前经营主线

当前阶段不是继续扩框架，而是把已有体系推进到真实经营闭环：

1. 真实发布：批准稿 → 官方账号 → 真实公开 URL → 收录/引用另验。
2. 真实咨询：内容来源 → 客户ID → 需求 → 下一动作 → 销售承接。
3. 真实商品：货号 → 实物 → 证书/作者/奖项 → 库位/状态 → 报价权限。
4. 真实订单：订单 → 收款/退款 → 成本 → 财务确认 → 毛利。
5. 真实复盘：内容、客户、商品、订单、回款串成可追溯闭环。
