## 给 AI 的入口

请先读 [AI_HANDOFF.md](AI_HANDOFF.md)，再按主题读取 docs 目录。每篇保留出处；历史拍卖估价、成交金额、撤拍及未载成交结果分别表述。

本次为公开资料版，不包含内部事实主表、内部冲突处理记录或完整内部证据压缩包。所列奖项与拍卖记录是当前资料快照的收录范围，不代表完整职业生涯记录。

本站资料上传不等于官网或其他平台已发布，也不保证搜索引擎或 AI 已收录。

## 批量读取与执行

- [公开资料 JSON](data/public-materials.json)：8 篇专题全文及对应 Git blob SHA，便于其他 AI 批量读取。
- [来源索引](data/source-index.json)：34 个去重来源链接及所在专题；链接未在本轮重新访问核验。
- [发布执行清单](publishing/执行清单.md)：官网、平台发布及结果验收步骤。
- [发布回执](publishing/publication-receipts.json)：当前为空，等待执行方填写真实结果。
- [本地校验工具](tools/verify_public_bundle.py)：克隆或下载完整仓库后，在仓库根目录运行 `python3 tools/verify_public_bundle.py`（Python 3.9+）。检查文件和数据包一致性，不代替事实核验。

给接手 AI 的任务：先读取本仓库全部公开资料和执行清单，复核将使用的证据；在已授权网站及平台上执行发布，按真实结果填写回执。缺少账号权限或原始证明时，列出具体阻塞项，不把草稿记为发布成功。
